# Project Plan

## Project Name

Production Linux Server Operations, Monitoring & Disaster Recovery Platform

## Objective

Build and manage a production-style Ubuntu Linux server
on AWS EC2 and demonstrate:

- Linux administration
- Storage management
- Service management
- Monitoring
- Logging
- Troubleshooting
- Security
- Automation
- Backup
- Disaster recovery

## Environment

Cloud:
AWS

Operating System:
Ubuntu Server LTS

Application:
Nginx

Automation:
Bash

Storage:
EBS
